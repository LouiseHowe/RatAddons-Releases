# RatAddons Releases

This repository contains the official compiled releases of **RatAddons**, a Fabric client mod for Hypixel SkyBlock.

The source code is maintained in a separate private repository. This repository contains release files and release notes only.

## Download

Download the latest `RatAddons-*.jar` file from the [Releases](https://github.com/LouiseHowe/RatAddons-Releases/releases/latest) page.

## Requirements

- Minecraft 26.1.2
- Fabric Loader 0.19.5 or newer
- Fabric API 0.155.3+26.1.2
- Java 25 or newer

## Installation

1. Install Fabric Loader and Fabric API for Minecraft 26.1.2.
2. Download the latest RatAddons jar from the Releases page.
3. Place the jar in your Minecraft `mods` folder.
4. Start the game and run `/rataddon` to open the settings screen.

## Updates

Each release includes the compiled mod jar and a summary of its changes. Only download RatAddons from this repository or another link published by the project owner.
